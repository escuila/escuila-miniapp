# Escuila — التطبيق المصغر

آخر تحديث: `20261004-product5` بتاريخ 4 أكتوبر 2026.

واجهة عربية للهاتف، بمكتبة وبحث ومفضلة ومساحة VIP ولوحة إدارة. تقرأ `data/` الموجود أولًا، وتتصل بخدمة البوت عندما تُفتح من Telegram للتحقق من الحساب والوصول والاشتراك وتحديث الفهرس.

هذه النسخة تضيف الرئيسية الجديدة، وفلاتر المستوى ونوع المورد والمدرسة الرائدة، وأحدث الموارد بصورها. تعرض مرفقات المورد وتصحيحاته المحفوظة بشروط الوصول الحالية، مع القراءة والتحميل المنفصلين واستخراج المدير للمرفقات من المصدر. تحسينات التنظيم وحذف القسم الفارغ ونقل موارده وحذف المسودات المؤرشفة باقية مع حفظ VIP.

ملفات الواجهة المعتمدة في جذر هذا المستودع: `index.html` و`app.js` و`discovery.js` و`admin-workspace.js` و`product.css` و`experience.css` وملفات التنسيق والقارئ الحالية. لا تحذف `data/` أو `assets/` أو `vendor/` عند رفع حزمة التحديث.

في مستودع البوت توجد النسخة المطابقة تحت `miniapp/`. المزامنة الآلية، إن كانت مضبوطة، ترفع هذه النسخة وبياناتها إلى مستودع التطبيق. ارفع تحديث البوت والتطبيق معًا حتى لا تعيد المزامنة واجهة قديمة.

بعد الرفع انتظر GitHub Pages، ثم أغلق التطبيق وافتحه من زر البوت. إدارة المحتوى تحتاج خدمة البوت ونفق الاتصال؛ التصفح الثابت يعمل دون جلسة.

التحسينات الأخيرة: إدارة الأقسام، استعادة المسودات، حماية التعديلات المحلية، عزل المفضلة بين الحسابات، تحديث المحتوى أثناء الاتصال، وتحسين النماذج واللمس والثيم الليلي.

`PROJECT_SUMMARY.md` يشرح البنية للمواصلة. تعليمات الهاتف وتقرير الفحص والاختبارات موجودة في مستودع البوت: `UPDATE_GUIDE_AR.md` و`REVIEW_REPORT_AR.md` و`TEST_REPORT_AR.md`.
